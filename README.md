# 多模态处理器

AstrBot 本地多模态文件处理插件：图片 / GIF 变换、格式转换与动图工具、QQ 图片保存、幻影坦克与光棱坦克、文本处理，以及基于 FFmpeg 的视频、音频处理。

全部在本地完成，不调用任何大模型 API。

</div>

## 安装

1. 在 AstrBot WebUI「插件市场」搜索安装，或上传仓库 zip；Python 依赖（Pillow、NumPy、aiohttp）会自动安装。
2. 视频和音频功能需要系统里有 **FFmpeg 与 FFprobe**（图片、QQ、幻影坦克、光棱坦克功能不需要）：

| 系统 | 安装命令 |
| :--- | :--- |
| Debian / Ubuntu | `sudo apt install ffmpeg` |
| CentOS / Rocky / Alma | 启用 EPEL 和 RPM Fusion 源后 `sudo dnf install ffmpeg` |
| Alpine | `apk add ffmpeg` |
| macOS | `brew install ffmpeg` |
| Windows | 下载 [FFmpeg 构建](https://www.gyan.dev/ffmpeg/builds/) 解压，在配置里填写 `ffmpeg.exe` / `ffprobe.exe` 的完整路径 |
| Docker 版 AstrBot | 进入容器执行 `apt update && apt install -y ffmpeg`，或在镜像里预装 |

装好后发送 `/多模态处理帮助`，末尾没有「未检测到 FFmpeg」即可。不在 PATH 里时，到配置「视频 → FFmpeg 可执行文件」填写完整路径。

## 指令

所有指令都可以：**引用**一条带媒体的消息后发送、**随指令附带**媒体，或附带**文件消息**（QQ 群文件、私聊文件）。图片类指令还可以 `@某人` 处理对方的 QQ 头像。同时有引用和附带时，引用的媒体优先。

发送 `/多模态处理帮助` 查看列表，`/多模态处理帮助 视频裁剪` 查看某条指令，`/多模态处理帮助 音频` 查看一个分类。

### 图片 / GIF

动图（GIF、动态 WebP、APNG）逐帧处理，保留每帧时长、循环次数和透明度。

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/反色` | | 反色，保留透明度 |
| `/顺时针` `/逆时针` | | 旋转 90° |
| `/左右翻转` `/上下翻转` | | 镜像翻转 |
| `/左对称` `/右对称` `/上对称` `/下对称` | | 保留一半并镜像到另一半 |
| `/调速` | `<倍率 0.1~10>` | GIF 调速，见下方说明 |
| `/GIF加速` `/GIF减速`（别名 `/加速` `/减速`） | `[倍数 1~10，默认 2]` | 等同于 `/调速 倍数`、`/调速 1/倍数` |
| `/图片转换` | `<png\|jpg\|webp\|gif\|bmp\|tiff> [静态]` | 格式转换，见下方说明 |
| `/图片压缩` | `[质量 1~100] [最长边]` | JPG/WEBP 按质量重编码，PNG/GIF 减少颜色；不缩小尺寸且结果反而更大时只提示、不发送 |
| `/图片缩放` | `<800x600 \| 800 \| x600 \| 50% \| 720p>` | 只给一边时等比缩放；`720p` 指短边 |
| `/图片裁剪` | `<x,y,宽,高 \| 宽:高>` | 例：`0,0,300,300`；`1:1`、`16:9` 从中心取最大区域 |
| `/图片信息` | | 格式、尺寸、帧数、总时长、循环、大小 |
| `/图片转线稿`（别名 `/线稿`） | | 铅笔素描风格线稿，支持动图 |
| `/表情包做旧`（别名 `/做旧`） | `[次数 1~50，默认 5]` | 模拟反复转发后发绿、变糊的老图；1～5 轻度，10～20 重度；支持动图 |

#### 动图工具

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/精灵图转GIF`（别名 `/合成GIF` `/合成1gif` `/合成2gif`） | `<行x列> [每帧时长] [边距…]` | 例：`/精灵图转GIF 6x6 0.05s 边距上10 左5`。按行从左到右取格子，末尾完全透明的空格会去掉 |
| `/多图合成GIF` | `[每帧时长，默认 0.5s]` | 把引用消息、当前消息、QQ 合并转发里的图片和 @ 用户的头像按顺序合成动图，以最大宽高为画布居中放置 |
| `/GIF分解` | `[最多帧数]` | 拆成单独的 PNG 帧；超过上限时均匀抽取 |
| `/网格切图`（别名 `/切图` `/网格裁剪`） | `<行x列> [边距…]` | 按行列切块，动图切出来仍是动图 |

- 每帧时长：`0.1`、`0.1s`（秒），`100ms`，或 `10fps`。
- 边距：`边距10`（四周）、`边距上20`、`边距 左 5`，可以写多个并叠加，先裁掉边距再按网格处理。
- 精灵图、多图合成的输出格式在配置里选（GIF / 动态 WebP / APNG）。`/GIF分解`、`/网格切图` 在 QQ 上用合并转发发送，其他平台每条消息最多 9 张。

**GIF 调速**：GIF 帧率有上限（默认 50 FPS，即每帧至少 20ms）。默认按「最短的那一帧」自动回退到不超限的最高倍率并提示；开启「GIF 调速允许丢帧」后改为合并连续短帧，达到目标倍率且总时长准确。

**动图转换**：转 `gif` / `webp` / `png` 默认保留动画（`png` 输出为 APNG）；加 `静态` 只取第一帧。`jpg` / `bmp` / `tiff` 不支持动画，会明确提示只保留了第一帧，透明区域填白。`bmp`、`tiff` 结果以文件发送。

### QQ 图片保存（仅 OneBot v11）

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/转换` | | 把引用的图片、GIF 或 QQ 官方表情重新发送为**可下载的文件**，保留原格式和动画 |
| `/外显取名` | `<文字>` | 重新发送图片，并把它在消息列表里的外显（如「[动画表情]」）改成指定文字；没写方括号会自动加上 |
| `/转换禁用` | `[群号]` | 管理员：禁止某群使用 `/转换`，不填群号为当前群（旧写法 `/convert addblock` 仍可用） |
| `/转换启用` | `[群号]` | 管理员：恢复某群（旧写法 `/convert delblock`） |

在群里发文件会进入群文件。默认把 `/转换` 的结果**私聊发给使用者**（非好友时尝试群临时会话），可在配置里改为直接发群或私聊失败再发群。禁用的群列表保存在配置「图片 → QQ：禁止使用 /转换 的群号」。

其他平台使用这两个指令会提示「QQ 专属功能」，不会报错。

### 幻影坦克

白色背景下显示表图，点开大图（黑色背景）显示里图。输出为 RGBA PNG。

| 指令 | 说明 |
| :--- | :--- |
| `/幻影坦克` | 黑白幻影坦克 |
| `/彩色幻影坦克`（别名 `/彩色幻影`） | 彩色幻影坦克，颜色参数见配置 |

两种用法：
- **一次给齐**：随指令附带两张图（第一张为表图），或引用一张、附带一张（引用的为表图）。
- **分步发送**：只发指令，按提示依次发送表图、里图；发送 `取消` 中止，超时自动取消。群里每个人的会话互相独立，别人发的图不会被收走。

里图会按表图尺寸居中裁剪对齐（不拉伸），输出最长边受配置限制。

### 光棱坦克

另一种隐藏图：里图的色阶被压到很暗的区间，按像素交错藏进表图里。平时看到的是（略暗的）表图，把暗部色阶拉开就能看到里图。

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/光棱坦克` | `[彩色\|黑白]` | 生成光棱坦克，表图是否保留颜色默认见配置；用法与幻影坦克相同（一次给两张图或分步发送） |
| `/光棱显形`（别名 `/光棱坦克显形`） | `[阈值 1~200]` | 还原里图：取出暗区像素、拉伸色阶并补齐交错的空隙 |

- 生成的 PNG 里记录了参数，`/光棱显形` 会优先读取；参数丢失时从亮度分布中自动找阈值，仍不理想可以手动指定，例如 `/光棱显形 48`。
- 也可以在修图软件里用「色阶」把输入范围设为 0～里图色阶端点（默认 32）手动显形。
- 光棱坦克依赖精确的像素值，转发时请发送**原图**；被聊天软件压缩后可能无法显形。

| :--- | :--- | :--- |
| `/去除MD格式` | `[文本]` | 去掉 Markdown 标记，转成纯文本 |
| `/添加MD格式` | `[文本]` | 给普通文本加上标题、加粗、列表、链接等 Markdown 格式 |
| `/MD代码块` | `[语言] 文本` | 包成 Markdown 代码块 |
| `/MD引用` | `[文本]` | 每行加上 > 变成引用 |
| `/MD列表` | `[有序] 文本` | 每行变成列表项 |
| `/MD表格` | `文本` | 把 CSV / TSV / 空格分隔的文本转成 Markdown 表格（首行为表头） |
| `/字数统计` | `[文本]` | 统计字符、汉字、单词、行数、段落 |
| `/全角转半角` | `[文本]` | 全角字母数字标点转半角 |
| `/半角转全角` | `[文本]` | 半角字符转全角 |
| `/转大写` | `[文本]` | 英文转大写 |
| `/转小写` | `[文本]` | 英文转小写 |
| `/清理空白` | `[文本]` | 去掉行首行尾空格、合并多余空格和空行 |
| `/文本去重` | `[文本]` | 删除重复的行（保留第一次出现） |
| `/文本排序` | `[倒序] 文本` | 按行排序（数字按大小） |
| `/文本反转` | `[文本]` | 把文字倒过来 |
| `/Base64编码` | `[文本]` | Base64 编码（UTF-8） |
| `/Base64解码` | `[文本]` | Base64 解码 |
| `/URL编码` | `[文本]` | URL 编码 |
| `/URL解码` | `[文本]` | URL 解码 |
| `/JSON格式化` | `[压缩] 文本` | 格式化 JSON（加「压缩」则压成一行） |
| `/文本哈希` | `[文本]` | 计算 MD5 / SHA1 / SHA256 |

例：`/MD代码块 python` 换行后接代码；`/MD表格` 换行后接「姓名,年龄」这样的多行数据。

### 视频（需要 FFmpeg）

时间可以写 `90`、`1:30`、`00:01:30.5`、`1分30秒`。

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/视频转GIF` | `[帧率] [宽度] [时长] [开始时间]` | 例：`/视频转GIF 12 480 5 1:05`；不填用配置默认值，帧率不超过原视频；调色板 + 抖动，画质和体积兼顾。也支持关键字写法，见下方 |
| `/GIF转视频` | | GIF / 动态 WebP / APNG 转 MP4（H.264），透明区域为黑色 |
| `/视频转换` | `<mp4\|webm\|mkv\|mov>` | 编码兼容时直接封装（秒级完成），否则转 H.264/AAC 或 VP9/Opus |
| `/视频压缩` | `[高\|中\|低\|CRF 18~40] [720p]` | 高/中/低 = CRF 23/默认值/33；第二个参数限制短边 |
| `/视频裁剪` | `<开始> <结束>` | 精确到帧（重新编码） |
| `/视频调速` | `<倍率 0.25~4>` | 音频用 atempo 保持音调，音画同步，帧率保持原值 |
| `/视频缩放` | `<1280x720 \| 1280 \| 720p \| 50%>` | 宽高自动取偶数，不超过输出分辨率上限 |
| `/视频旋转` | `<90\|180\|270\|-90>` | 90 为顺时针 |
| `/提取音频` | `[mp3\|m4a\|wav\|ogg\|flac\|opus]` | 默认 mp3；AAC 转 m4a 时直接复制音轨 |
| `/视频静音` | | 去掉音轨，画面不重新编码 |
| `/视频截图`（别名 `/提取视频帧`） | `[时间]` | 指定时间的画面，输出 PNG |
| `/视频信息` | | 容器、时长、分辨率、帧率、编码、码率 |

`/视频转GIF` 的关键字写法可以和上面的位置参数混用：`2s-4.5s` 或 `1:05-1:09`（时间段）、`开始 2`、`时长 3`、`fps15` / `15fps`、`1/3`（每 3 帧取 1 帧）、`0.5` 或 `50%`（按原视频宽度缩放）。例：`/视频转GIF 2s-4.5s fps15 50%`。小于 1 的小数会被当作缩放比例。

### 音频（需要 FFmpeg）

视频文件也可以作为音频指令的输入（自动取音轨）。QQ 语音（SILK）会先自动解码。

| 指令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `/音频转换` | `<mp3\|wav\|ogg\|m4a\|flac\|opus>` | 快捷写法：`/音频转MP3` `/音频转WAV` `/音频转OGG` `/音频转M4A` `/音频转FLAC` |
| `/音频裁剪` | `<开始> <结束>` | |
| `/音频调速` | `<倍率 0.25~4> [变调]` | 默认保持音调；加 `变调` 像磁带变速 |
| `/音量`（别名 `/音频音量`） | `<1.5 \| 50% \| +6dB \| -3dB>` | 放大时自动限幅防爆音 |
| `/音频压缩` | `[码率，默认 64k]` | MP3/M4A/OGG/OPUS 保持格式，其他转 MP3 |
| `/音频静音` | `<开始> <结束>` | 把一段时间静音 |
| `/去除静音`（别名 `/音频去静音`） | `[阈值 dB，默认 -50] [最短静音秒数，默认 0.5]` | 删除静音片段 |
| `/音频信息` | | 格式、时长、编码、采样率、码率 |

音频结果默认「群聊发语音（不占群文件）、私聊发文件（保留格式可下载）」，可在配置里改。

### 精准关键词模式

默认所有指令都要带唤醒前缀（如 `/`）。开启「通用 → 精准关键词匹配」后，引用媒体直接发送 `反色`、`调速 2`、`视频转GIF` 也能触发：必须整条消息就是指令（后面只能跟参数），而且**找到媒体才会响应**，所以不会误触普通聊天。帮助、幻影坦克、光棱坦克、管理指令始终需要前缀。

QQ 里回复别人时客户端会自动插入 `@对方`，导致 AstrBot 不识别后面的 `/指令`；插件会自动识别这种情况，无需开启关键词模式。

## 资源与安全

- 所有处理都在后台线程或 FFmpeg 子进程中进行，不阻塞 AstrBot；FFmpeg 只用参数列表启动，不经过 shell。
- 每个任务独占一个临时目录（`data/plugin_data/multimodal_processor/tasks/`），结果**发送完成后**立即删除，失败、取消、超时同样清理；另有定期过期清理兜底。
- 下载为流式写盘，超过大小限制立即中断；文件类型按文件头识别，不信任扩展名。
- 单个任务出错只会回复错误提示，不会影响 AstrBot 和其他插件。

## 平台支持

| 功能 | QQ（aiocqhttp） | 其他平台 |
| :--- | :--- | :--- |
| 图片 / GIF、动图工具、幻影坦克、光棱坦克 | ✅ | ✅（需平台支持发送图片） |
| 视频 / 音频 | ✅ | ✅ 平台不支持视频或语音时改为文件发送；QQ 官方机器人、钉钉等只能发图片的平台会提示不支持 |
